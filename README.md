# Case-a-thon

A project developed for Case-a-thon focused on leveraging technology to improve marine research and academic collaboration.

## Overview

This project includes two components:

* **Benthic Sea Image Classification:** A machine learning model designed to analyze benthic sea images and classify marine organisms, helping support biodiversity research and improve the identification of underwater species.

* **Student-Professor Collaboration Platform:** A website designed to strengthen student-professor relationships by creating opportunities for improved communication, mentorship, and academic engagement.

Together, these components explore how technology can support both scientific discovery and educational connections.

## Technologies

* Machine Learning
* Image Classification
* Web Development
* Data Processing

## Project Goals

* Apply artificial intelligence to assist with marine image analysis.
* Improve accessibility and efficiency in identifying benthic marine organisms.
* Create tools that encourage stronger connections between students and professors.
